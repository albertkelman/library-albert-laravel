# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository
2. Jalankan `composer install`
3. Copy `.env.example` ke `.env`
4. Konfigurasi database di `.env`
5. Jalankan `php artisan migrate`
6. Jalankan `php artisan serve`
